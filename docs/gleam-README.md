# A Dark Room — Gleam + Lustre port

A faithful 1:1 port of [A Dark Room](https://github.com/doublespeakgames/adarkroom)
to **Gleam** + **[Lustre](https://lustre.build)** (Elm-style MVU), compiled to
JavaScript and bundled with Vite.

See [`gleam-port-design.md`](gleam-port-design.md) for the
architecture and the M0–M8 milestones.

## Prerequisites

- [Gleam](https://gleam.run) 1.15+ (pinned via `mise.toml`)
- Node.js 22 (for Vite and the `.po` pipeline; pinned via `mise.toml`)

## Develop

```sh
mise trust         # once: allow the pinned gleam toolchain (mise users)
npm install        # once: install Vite
npm run dev        # gleam build + Vite dev server (http://localhost:5173)
```

Gleam sources live in `src/`. After changing `.gleam` files, run `gleam build`;
Vite picks up the recompiled modules and reloads the page.

## Build / preview

```sh
npm run build      # gleam build + vite build -> dist/
npm run preview    # serve the production build locally
```

## Test

```sh
gleam test
```

## Layout

- `src/adarkroom.gleam` — app entry (Model / update / view)
- `main.js` — browser entry; imports the compiled Gleam and starts Lustre
- `index.html` — Vite entry; mounts into `#app`, links the existing stylesheet
- `public/css`, `public/audio` — symlinks into `adarkroom-js/` (the original keeps the assets; single source of truth)
- `public/lang/` — generated by `npm run i18n` (`scripts/po2json.mjs`) from the original's `.po` files; committed, and CI fails if it drifts
